# Banquet Hall CRM

A corporate CRM system designed to automate the banquet hall reservation process for a restaurant chain.

The application replaces manual booking workflows with a centralized platform, allowing employees to manage clients and reservations through a modern, responsive interface.

The frontend application was fully developed by me using the modern React ecosystem and integrated with a REST API backend.

## Project Overview

The system was developed for employees of a restaurant chain to simplify the reservation process for banquet halls.

Instead of managing bookings manually, employees work with a single platform where they can:

- manage clients;
- create reservations;
- choose restaurants;
- select banquet halls;
- specify reservation dates;
- keep booking information centralized.

The project focuses on improving operational efficiency while providing an intuitive interface for everyday use.

## О проекте

**Banquet Hall CRM** — корпоративная CRM-система, разработанная для автоматизации процесса бронирования банкетных залов в сети ресторанов.

Проект заменяет ручной процесс ведения бронирований единой современной платформой, позволяющей сотрудникам быстро работать с клиентами и создавать новые бронирования.

Основные возможности системы:

- ведение клиентской базы;
- поддержка физических и юридических лиц;
- создание бронирований;
- выбор ресторана;
- выбор банкетного зала;
- выбор даты мероприятия;
- централизованное управление бронированиями.
